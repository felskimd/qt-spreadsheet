# qt-spreadsheet
Приложение на Qt на основе https://github.com/felskimd/cpp-spreadsheet

## Реализовано:
* Qt-модель для связи оригинальной модели таблицы и QTableView
* Импорт/экспорт таблиц в формате csv

## Будет реализовано:
* Действия с ячейками (копировать, удалить, вставить, сдвинуть) с поддержкой Qt Undo Framework
* Импорт/экспорт таблиц других форматов
