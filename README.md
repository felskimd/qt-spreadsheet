# qt-spreadsheet
Qt приложение на основе https://github.com/felskimd/cpp-spreadsheet

## Реализовано:
* Qt-модель для связи оригинальной модели таблицы и QTableView
* Импорт/экспорт таблиц в формате csv
* Тестирование модели
* Действия (копировать в буфер обмена, удалить, вставить из буфера, вырезать)

## Будет реализовано:
* Внедрить Qt Undo Framework
* Импорт/экспорт таблиц других форматов
